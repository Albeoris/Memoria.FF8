# Translator-focused localization workbench audit

This audit follows text from canonical resource resolution to the renderer and the selected editing destination. Exporting a row is not evidence that its renderer supports selection, preview or live refresh. The review covers the integrated authoring implementation and its portable storage foundation; it does not establish original-game deployment or complete native visual parity. Historical reproductions remain below so each correction can be assessed against its original defect. The closure table distinguishes passing checks, implemented paths and pending verification.

## Language and storage contracts

Source Scripts determine inventory, keys and native call contracts. Source Reference independently determines source-seeded prose. Target is the only writable translation string, including its leading presentation prefix. Reference ordering does not change those roles. Missing/null/empty Targets contribute no runtime override; explicit presence flags must also govern source materialization.

The Resources-only authoring assembly holds drafts, immutable concurrency evidence, editable conflict candidates, selective saved-change replay and user recovery state. Mods owns JSON/XLSX updates, complete row/dependency revisions, verified missing-row insertion and recoverable manifest/payload/sidecar publication. The host owns the selected destination, temporary overlays and live-generation publication. See the [acyclic dependency/reference audit and context contracts](localization-authoring.md#dependency-and-ownership-audit), [language roles and file format](../modding/localization.md), [player workbench guide](../players/localization-workbench.md) and [font/profile namespaces](../modding/encoding-profiles.md).

The confirmed storage blockers are repaired: write-existing saves no longer reconstruct exports; source/reference and unknown metadata remain intact; workbook role cells are patched while ancillary parts survive; canonical revisions distinguish same-row edits from unrelated rows/formatting; new resource families update declarations and native metadata coherently. Twenty focused storage cases passed, and the broader localization selection passed 129 cases with one explicitly optional installed-resource skip. This does not replace final host/renderer verification.

## Verification limits

Portable storage regression coverage includes complete row conflicts, explicit source roles, missing/null/empty Targets, unknown metadata, ancillary workbook parts, generic missing-family insertion, recoverable new-file transactions and independent replay. Renderer/host checks must additionally cover the final production draw and lifecycle paths; a passing exporter or parser test alone does not close a renderer finding.

The audit uses redistributable synthetic inputs, source inspection and explicitly configured optional installed-resource checks. No original assets or private evidence are distributed with it. Native-style presentation, native-resource compatibility and original-game deployment are separate claims. A mixed-atlas rendering pass or installed field test does not establish the other claims or complete M5.

The rebased host also passed a final Native-only installed workflow with inspected Preview, editable conflict and final menu captures. All nine distinct translated level arguments, ordinary names, HP, time/rank and navigation render; the final native diagnostic is empty. A focused post-rebase selection passed 38 cases with one optional installed-resource case unavailable in that invocation; the separately configured installed workflow passed. Profile duplication additionally remaps only self-references, preserves external namespaces and passes the 22-case encoding selection.
