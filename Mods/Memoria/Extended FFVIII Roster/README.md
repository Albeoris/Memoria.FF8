# Extended FFVIII Roster

The mod is off by default. Enable **Extended FFVIII Roster** in **Mods** on the Classic edition to make Laguna, Kiros, Ward, Edea and Seifer available through **Switch Member** when the game allows party changes. Story scenes keep their original actors and party rules.

Permanent Laguna, Kiros and Ward start at level 1 with their original weapons, full HP and empty magic and junctions. Edea and Seifer use their original saved records. Dreams still use the original party records for their temporary versions.

The mod also enables mapping these five characters to FFVII. The mapping always uses each character's original identity and permanent progress, including when the departure point is in a dream.

Disabling the mod removes these characters from the regular party. Squall returns if it would otherwise be empty. Use a Memoria save to retain their progress while the mod is disabled.
