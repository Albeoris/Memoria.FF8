# Meltdown

Meltdown changes the effect of Vit0, regardless of how the status was applied. It reduces Vitality by 50% and Spirit by 25% by default. Adjust either percentage in the Memoria mod settings. Hardcore requires the mod and uses its declared defaults.

The status name follows the localized Meltdown spell name. The mod descriptor is in `mod.json` and the status definition is in `statuses/vit0.json`.
