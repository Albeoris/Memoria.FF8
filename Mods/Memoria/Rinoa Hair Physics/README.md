# Rinoa Hair Physics

Enable **Rinoa Hair Physics** under **Mods** to give Rinoa's hair secondary motion in field scenes. The mod is off by default and supports Classic and Remastered.

The `.springs.glb` profiles in `models/field/main_chr/` use the glTF `VRMC_springBone` extension. Each profile targets one installed character model. The installed animations drive the hair's resting pose, and the springs add movement as Rinoa moves or turns.
