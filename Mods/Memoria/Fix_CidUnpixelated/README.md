# Fix_CidUnpixelated

This native Memoria field mod hides the pixelated Cid background image in the Balamb Garden hall speech and uses the field's own Cid model for his actor. All models, animations and background pixels are loaded from the user's installed game. This package contains only scene configuration.

The package inherits the standard automatic enablement policy. Enable or disable `Memoria/Fix_CidUnpixelated` through the Mods menu, or create `mod.ini` containing `enabled = 0` to disable it. No installed game files are changed.

See `docs/modding/field-mods.md` in the source distribution for the format and the Scene inspector in Debug Room (F2) for scene inspection. Ordinary development builds add missing bundled files without overwriting edits. Launcher updates replace untouched bundled defaults and preserve edited or pre-existing mod files.
